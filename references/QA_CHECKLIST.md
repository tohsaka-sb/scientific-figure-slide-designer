# Figure and slide release checklist

## Scientific structure
- [ ] One-sentence slide claim is clear.
- [ ] Each node maps to a real method component or declared conceptual abstraction.
- [ ] Comparison panels use matching levels of abstraction and equivalent roles.
- [ ] Local versus shared memory and read versus write links are correctly depicted.
- [ ] Candidate admission, support/refute/uncertain evidence, dependencies, and state updates are distinguished where relevant.
- [ ] Feedback arrows point to the correct stage; stages are neither missing nor silently reordered.
- [ ] Future plans are not presented as completed experiments.

## Design and readability
- [ ] Reference aesthetics respected while avoiding direct copying of protected art.
- [ ] 16:9 or exact template dimensions retained.
- [ ] Chinese and English text checked at full resolution.
- [ ] Labels survive projected/thumbnail viewing.
- [ ] Aligned cards and consistent icon style, arrow weight, and type hierarchy.
- [ ] No overflowing or obscured text; balanced use of vertical/horizontal space.
- [ ] No cluttered footnotes or excessive decorative gradients.

## Deliverables
- [ ] PPTX built from the original provided template when applicable.
- [ ] Key components (text, panels, lines) are editable.
- [ ] Embedded icons are separate images (not flattened whole-slide screenshot).
- [ ] Open/render PPTX; verify no corruption or clipping.
- [ ] Requested transparent PNG is truly RGBA with alpha=0 for external background.
- [ ] Inspect transparent PNG against black, white, and checkerboard.
- [ ] Verify output files actually exist before linking.
